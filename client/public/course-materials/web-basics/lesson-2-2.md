# Формы и поля ввода

Формы нужны, чтобы пользователь мог отправлять данные: зарегистрироваться, войти в аккаунт, оставить комментарий, оформить заказ или написать сообщение.

Основной тег формы — `form`. Внутри него размещаются поля ввода и кнопка отправки.

Полезные теги:

- `label` — подпись к полю.
- `input` — однострочное поле ввода.
- `textarea` — многострочное поле.
- `select` — выпадающий список.
- `button` — кнопка.

У `input` есть разные типы: `text`, `email`, `password`, `number`, `date`, `checkbox`, `radio` и другие. Тип помогает браузеру правильно проверять данные и показывать удобную клавиатуру на телефоне.

Важно связывать `label` и `input` через `for` и `id`. Это делает форму понятнее и удобнее для пользователей, в том числе для тех, кто использует вспомогательные технологии.

Пример формы регистрации:

```html
<form>
  <label for="name">Имя</label>
  <input id="name" type="text" name="name" />

  <label for="email">Email</label>
  <input id="email" type="email" name="email" />

  <label for="password">Пароль</label>
  <input id="password" type="password" name="password" />

  <button type="submit">Зарегистрироваться</button>
</form>
```

Форма должна быть понятной: у каждого поля есть подпись, а кнопка ясно сообщает, что произойдёт после нажатия.
