# Основы JavaScript

JavaScript добавляет странице интерактивность. С его помощью можно реагировать на действия пользователя, изменять содержимое страницы, проверять формы и отправлять запросы на сервер.

Переменные позволяют хранить данные. `let` используют для значений, которые могут изменяться, а `const` — для значений, которые не нужно переназначать.

```js
const courseName = "Основы веб-разработки";
let completedLessons = 0;
```

Типы данных описывают, какие значения мы храним: строки, числа, булевы значения, массивы, объекты и другие.

Условия `if` позволяют выполнять код только при определённом условии.

```js
if (completedLessons > 0) {
  console.log("Обучение начато");
}
```

Функции помогают объединять повторяющиеся действия в отдельные блоки.

События позволяют реагировать на клики, ввод текста, отправку формы и другие действия пользователя.

`console.log` выводит сообщение в консоль и часто используется для проверки работы кода.

Пример обработки клика:

```js
const button = document.querySelector("#button");

button.addEventListener("click", () => {
  console.log("Кнопка нажата");
});
```

JavaScript лучше изучать на маленьких практических задачах: кнопка, счётчик, переключатель темы, проверка формы.
