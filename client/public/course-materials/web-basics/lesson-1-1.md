# Что такое сайт и как он работает

Сайт — это набор страниц и файлов, которые пользователь открывает через браузер. На странице могут быть текст, изображения, кнопки, формы, видео и другие элементы.

Frontend — это видимая часть сайта: структура страницы, внешний вид и взаимодействие пользователя с интерфейсом. Именно frontend отвечает за то, как выглядит страница, как нажимаются кнопки и как пользователь перемещается по сайту.

Backend — это серверная часть. Она хранит данные, проверяет авторизацию, обрабатывает запросы, работает с базой данных и возвращает frontend нужную информацию.

Браузер — программа, которая получает файлы сайта, читает HTML, CSS и JavaScript, а затем показывает страницу пользователю.

Клиент-серверная архитектура означает, что есть клиент и сервер. Клиентом обычно выступает браузер пользователя. Сервер принимает запросы, выполняет нужную работу и отправляет ответ.

Когда пользователь открывает страницу, браузер отправляет запрос на сервер. Сервер возвращает HTML, CSS, JavaScript и данные. Браузер собирает всё вместе и показывает готовую страницу. Если пользователь нажимает кнопку или отправляет форму, браузер может снова обратиться к серверу.

Главная мысль урока: сайт — это совместная работа браузера, frontend-кода, backend-сервера и данных.
