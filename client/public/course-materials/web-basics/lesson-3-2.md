# Flexbox и адаптивность

Flexbox — способ удобно выстраивать элементы в ряд или колонку. Он особенно полезен для меню, карточек, кнопок и блоков, которые должны красиво распределяться внутри контейнера.

Чтобы включить Flexbox, контейнеру задают `display: flex`.

```css
.cards {
  display: flex;
  gap: 20px;
  flex-wrap: wrap;
}
```

`justify-content` управляет расположением элементов по главной оси. Например, можно распределить элементы по краям или выровнять по центру.

`align-items` управляет выравниванием по поперечной оси. Часто используется значение `center`.

`gap` задаёт расстояние между элементами без лишних `margin`.

`flex-wrap` разрешает элементам переноситься на новую строку, если места не хватает.

Адаптивная вёрстка нужна, чтобы сайт хорошо выглядел на компьютере, планшете и телефоне. Для этого используют гибкие сетки, относительные размеры и media queries.

Пример адаптивной сетки карточек:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

@media (max-width: 768px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
```

Цель адаптивности — не просто «уместить» сайт на маленьком экране, а сохранить удобство чтения и навигации.
