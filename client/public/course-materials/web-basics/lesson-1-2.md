# Инструменты разработчика

Веб-разработчик использует несколько базовых инструментов. Они помогают писать код, проверять результат, искать ошибки и сохранять изменения.

Редактор кода нужен для удобного написания HTML, CSS и JavaScript. Он подсвечивает синтаксис, помогает находить ошибки и быстрее перемещаться по проекту.

VS Code — один из самых популярных редакторов кода. В нём можно открывать папку проекта, устанавливать расширения, запускать терминал и удобно работать с файлами.

Браузер нужен не только для просмотра сайта. В нём разработчик проверяет, как страница выглядит на разных размерах экрана и как работает интерактивность.

DevTools — инструменты разработчика внутри браузера. С их помощью можно смотреть HTML-структуру, CSS-стили, ошибки JavaScript, сетевые запросы и скорость загрузки страницы.

Терминал нужен для запуска команд: установки зависимостей, запуска проекта, работы с Git и выполнения вспомогательных задач.

Git — система контроля версий. На базовом уровне Git помогает сохранять историю изменений проекта и возвращаться к предыдущим версиям, если что-то сломалось.

Минимальный набор начинающего frontend-разработчика: VS Code, браузер, DevTools, терминал и Git.
