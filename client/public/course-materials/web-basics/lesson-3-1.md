# Основы CSS

CSS — язык стилей. Он отвечает за внешний вид HTML-элементов: цвета, размеры, шрифты, отступы, фон, рамки и расположение.

CSS-правило состоит из селектора и набора свойств. Селектор выбирает элемент, а свойства описывают, как он должен выглядеть.

```css
p {
  color: #1f2937;
  font-size: 18px;
}
```

Цвет можно задавать словами, HEX-кодами, RGB/RGBA или HSL. В современных интерфейсах удобно хранить основные цвета в CSS-переменных.

Размеры часто задаются в `px`, `%`, `rem`, `em`, `vw` и `vh`. Для текста и отступов часто удобны `rem`, потому что они лучше масштабируются.

`margin` — внешний отступ элемента. Он отделяет элемент от соседей.

`padding` — внутренний отступ. Он создаёт пространство между содержимым элемента и его границей.

`border` добавляет рамку, `border-radius` скругляет углы, `background` задаёт фон, а `font-size` управляет размером текста.

Пример карточки:

```css
.card {
  padding: 20px;
  border-radius: 16px;
  background: white;
  box-shadow: 0 10px 30px rgba(0, 0, 0, 0.08);
}
```

Хороший CSS делает интерфейс не просто красивым, а читаемым и удобным.
