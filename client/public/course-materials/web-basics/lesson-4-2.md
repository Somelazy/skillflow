# Итоговый мини-проект

Итоговый проект курса — адаптивная landing page для вымышленного онлайн-курса. Это небольшая страница, которая показывает, чему посвящён курс, почему он полезен и как оставить заявку.

Требования к проекту:

- `header` с названием сайта и навигацией.
- Hero-блок с крупным заголовком, коротким описанием и кнопкой.
- Секция преимуществ платформы.
- Карточки курсов или модулей.
- Форма обратной связи.
- Адаптивность для мобильных устройств.
- Небольшая интерактивность на JavaScript.

Рекомендуемая структура файлов:

```text
project/
  index.html
  styles.css
  script.js
```

В HTML создай смысловые блоки: `header`, `main`, `section`, `footer`. В CSS оформи типографику, сетки, карточки, кнопки и мобильную версию. В JavaScript добавь простое событие, например вывод сообщения после нажатия на кнопку или проверку формы.

Пример идеи интерактивности:

```js
const form = document.querySelector(".contact-form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  alert("Спасибо! Мы свяжемся с вами.");
});
```

Этот проект собирает вместе всё, что было в курсе: HTML-структуру, CSS-оформление, адаптивность и базовый JavaScript.
